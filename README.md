# Aesthetic Stopwatch Replica

This project is a replica of the [Aesthetic Stopwatch by Flocus](https://flocus.com/aesthetic-stopwatch/), developed as part of my freelance work with Outlier AI for training artificial intelligence models in frontend development.

## Description

The app is a web page built with HTML and Tailwind CSS that closely reproduces the interface and visual experience of the original Flocus Aesthetic Stopwatch. The goal is to showcase skills in layout, responsive design, and attention to detail by faithfully replicating the modern, minimalist aesthetic.

## Key Features

- **Responsive, Minimalist Design:** Inspired by Flocus, leveraging Tailwind CSS for a clean and professional look.
- **Functional Stopwatch:** Start, pause, and reset the timer, with clear and accurate time display.
- **Intuitive Interface:** Large buttons, clear typography, and soft color palette for a pleasant user experience.
- **Optimized Code:** Simple, easy-to-maintain structure, ideal for portfolios and AI training in frontend tasks.

## About the Original

[Flocus Aesthetic Stopwatch](https://flocus.com/aesthetic-stopwatch/) is an online stopwatch designed for productivity, study, meditation, and more. It stands out for its aesthetic themes, ambient sounds, and focus statistics. This replica aims to capture the core visual and basic functional essence of the original tool.
